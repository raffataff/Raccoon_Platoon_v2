# Config Reorganization Plan

## Goal
Organize `js/config.js` into logical sections to improve maintainability. Support future separation into multiple files when additional biomes are added.

## Current Issues
1. Inconsistent section header styles (`// ---` vs `// --- `)
2. Comments wedged between unrelated settings (e.g., `VIDEO SETTINGS` between `WORLD_MUD_NOISE_OCTAVES` and `MIN_LOADING_VIDEO_DURATION_MS`)
3. Related settings scattered (e.g., raccoon grenade settings split across 3 locations)
4. Unit stats for same entity not grouped (e.g., RACCOON_* stats scattered)
5. Biome-specific sprite paths mixed with general config
6. Massive `OBSTACLE_DEFINITIONS` and `PICKUP_DEFINITIONS` arrays hard to navigate
7. Some sections well-structured (AI), others chaotic

---

## Proposed Structure

```

MAX_DELTA_TIME_STEP, CAMERA_LERP_SPEED, CAMERA_ZOOM
```

### 2. INPUT

```

```

### 3. VIDEO

```

```

### 4. PATHFINDING_AI
Pathfinding, unit stuck detection, and enemy alert settings.
```

UNIT_STUCK_FRAMES_THRESHOLD, STUCK_FRAMES_THRESHOLD_PATHING, REPATH_STUCK_COOLDOWN

ENEMY_ALERT_ON_DMG_THRESHOLD_PERCENT

```

### 5. PLAYER_RACCOON
All player raccoon settings grouped by category:
- **Base Stats**: HP, SPEED, SIZE, COLOR, DETECTION_RANGE
- **Engagement**: MIN_ENGAGEMENT_DISTANCE, PREFERRED_ENGAGEMENT_DISTANCE_MAX, ENGAGE_RANGE_BUFFER
- **Machine Gun**: MG_DAMAGE, MG_ROF, MG_RANGE, MG_PROJECTILE_SPEED, MG_ACCURACY_*
- **Grenades**: GRENADE_DAMAGE, GRENADE_AOE_RADIUS, GRENADE_FUSE_TIME, GRENADE_THROW_RANGE_MAX, GRENADE_THROW_COOLDOWN, GRENADE_PROJECTILE_SPEED, GRENADE_PREFERRED_THROW_RANGE_FACTOR, STARTING_GRENADES
- **Ammo/Reload**: STARTING_AMMO, MAGAZINE_SIZE, BASE_RELOAD_TIME, RELOAD_TIME_REDUCTION_PER_RANK
- **Auto-target**: AUTO_TARGET_RANGE_FACTOR
- **Sprites**: All sprite paths and scale factors for each rank (Recruit through Maverick), plus DEAD sprites

### 6. ENEMY_UNITS
Group enemy unit settings by type. Each unit group contains:
- Base Stats: HP, SPEED, SIZE, COLOR
- Weapon Stats: DAMAGE, ROF, RANGE, PROJECTILE_SPEED, ACCURACY_*, BULLET_LIFETIME
- Sprites: SPRITE_PATH, SCALE_FACTOR, DEAD_SPRITE_PATH, DEAD_SPRITE_FILES, DEAD_SPRITE_SCALE

**Unit groups:**
- Possum Grunt
- Possum Heavy
- Possum Boss 1 (includes SECONDARY_WEAPON)
- Possum Revolver
- Possum Sniper
- Possum Elite

## Implementation Notes

### Phase 1: Internal Reorganization (This Task)
Restructure within the single file. Add consistent section headers:
```javascript
// =============================================================================
// SECTION_NAME
// =============================================================================
```

### Phase 2: File Separation (Future)
When adding a second biome, split into:
- `config/core.js` - Core settings
- `config/player.js` - Player raccoon
- `config/enemies.js` - Enemy units
- `config/world.js` - World/terrain settings
- `config/biomes/tropical.js` - Tropical sprites
- `config/biomes/swamp.js` - Swamp sprites (new)
- `config/level.js` - Level generation
- `config/audio.js` - Audio
- `config/ui.js` - UI
- `config/shootout.js` - Shootout mode

### Key Principles Applied
1. **Group by entity/system**: All settings for a unit type are together
2. **Biome-specific isolated**: Tropical sprites separated for future biome files
3. **Logical dependencies**: AI behavior comes after unit definitions
4. **Alphabetize within reason**: Settings like `HP`, `SIZE`, `SPEED` maintain consistent order within unit groups
