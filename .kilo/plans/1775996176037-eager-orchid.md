# Plan: Expandable Weapon System with Config-Based Values

## Current State
- Weapons defined in `js/weapon.js` (WEAPONS constant, lines 18-154)
- Weapon values scattered across `js/config.js` with prefixes (e.g., `POSSUM_HEAVY_WEAPON_DAMAGE`)
- Units hardcode weapon assignment in constructors
- No weapon pickup crates exist
- Raccoon weapons (7 variants) share same stats, differ only in color/name
- Possum weapons (9 types) each have distinct stats

## Goal
Enable adding new weapons via config with weapon crates (for raccoons only) and simple string-based unit references.

## Phase 3: Weapon Pickup System (Raccoons Only)

### 3.1 Understanding the Weapon System

Each raccoon has:
- **defaultWeaponName**: Based on their rank (e.g., Recruit→`RACCOON_MACHINE_GUN`, Private→`RACCOON_PRIVATE_MG`)
- **currentWeaponName**: Currently equipped weapon (starts as default)
- **defaultAmmo**: Ammo count for the default weapon (infinite or replenished by ammo crates)
- **specialAmmo**: Ammo count for picked-up weapon (limited, depletes)

When special weapon ammo depletes → auto-switch back to default weapon.

## Phase 4: Update Ammo System

### 4.1 Raccoon Ammo Properties

Each raccoon has two ammo pools:
- `defaultAmmo`: Ammo for their default weapon (starts at `RACCOON_STARTING_AMMO`, replenished by ammo crates)
- `specialWeaponAmmo`: Ammo for picked-up advanced weapon (starts at weapon's `maxAmmo`, depleted by firing)

Update `Raccoon` constructor to track both:
```javascript
this.defaultAmmo = CONFIG.RACCOON_STARTING_AMMO;
this.specialWeaponAmmo = 0;
```

### 4.2 Firing with Ammo Check

In `Unit._executeFire()` or `Raccoon._executeFire()`:
```javascript
_executeFire(targetX, targetY) {
    // Check if can fire
    const weaponDef = CONFIG.WEAPON_DEFINITIONS[this.currentWeaponName];
    
    // Determine ammo pool and check
    if (weaponDef && weaponDef.isDefaultWeapon) {
        if (this.defaultAmmo <= 0) return;  // Out of ammo
        this.defaultAmmo--;
    } else {
        if (this.specialWeaponAmmo <= 0) {
            // Switch back to default weapon
            this.currentWeaponName = this.defaultWeaponName;
            this.weaponName = this.defaultWeaponName;
            return;
        }
        this.specialWeaponAmmo--;
    }
    // ... rest of firing logic
}
```

### 4.3 Display Ammo Count

In HUD/UI, show current ammo:
- If using default weapon: `defaultAmmo` / ∞
- If using special weapon: `specialWeaponAmmo` / `maxAmmo`

## Weapon Properties Reference

Each weapon definition requires:

| Property | Type | Description |
|----------|------|-------------|
| `name` | string | Display name |
| `damage` | number | Damage per hit |
| `rof` | number | Rate of fire (shots/second) |
| `range` | number | Maximum firing range (pixels) |
| `projectileSpeed` | number | Bullet travel speed (pixels/sec) |
| `projectileColor` | string | Hex color for projectiles |
| `accuracyStationary` | number | Accuracy when stationary (0-1) |
| `accuracyMoving` | number | Accuracy when moving (0-1) |
| `sfxFireKey` | string | Audio manager key for fire sound |
| `muzzleFlashScale` | number | Muzzle flash effect size multiplier |
| `bulletLifetime` | number | Seconds before bullet despawns |
| `isDefaultWeapon` | boolean | If true, cannot be swapped, infinite ammo (raccoon default weapons only) |
| `maxAmmo` | number | Max ammo for this weapon (Infinity for default weapons) |
| `phaseUnlocked` | number | Minimum phase required to spawn as crate (advanced weapons only) |
| `pelletCount` | number | Optional: projectiles per shot (e.g., shotgun) |

## Notes
- Weapon name strings must be UPPER_SNAKE_CASE to match WEAPONS keys
- Weapon crates are for raccoons only (team === 'player')
- User will provide actual crate image paths (`spriteWithWeapon`, `spriteWithoutWeapon`)
- New weapons added to WEAPON_DEFINITIONS automatically available via weaponName
- Enemy units (possums) don't use the ammo system - they fire continuously
- Ammo crates replenish the current weapon's ammo (default or special)
- When special weapon ammo hits 0, auto-switch back to default weapon
- Weapon crates are phase-unlocked: only spawn weapons where `weapon.phaseUnlocked <= currentPhase`
- `isDefaultWeapon: true` weapons cannot be picked up from crates
