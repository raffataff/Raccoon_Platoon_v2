# Plan: Replace Mugshot with Rank Image in Debrief Unit Cards

## Goal
Replace the raccoon mugshot (face image) in the debrief screen's unit cards with the rank icon image. The dogtag sprite will be used as a background for the unit details section where name, rank, and XP are displayed.

## Current Structure
```
.unit-card (flex column)
├── .unit-card-sprite-section (top - rotating sprite)
└── .unit-card-info-row (bottom)
    ├── .unit-card-face-section → .card-face (mugshot via faceImageUrl)
    └── .unit-card-details (name, rank, xp)
```

## Changes Required

### 1. JS Changes (`js/ui.js` - `_createPostMissionRecruitCard` function around line 1886-1889)

**Before:**
```javascript
const faceDiv = document.createElement('div');
faceDiv.className = 'card-face';
faceDiv.style.backgroundImage = `url('${recruit.faceImageUrl}')`;
```

**After:**
```javascript
const faceDiv = document.createElement('div');
faceDiv.className = 'card-face';
const rankIconConfig = CONFIG.UI_SETTINGS?.RANK_ICON_FILES;
const rankIconPath = CONFIG.UI_SETTINGS?.RANK_ICON_PATH;
if (rankIconConfig && rankIconPath && rankIconConfig[recruit.rank]) {
    faceDiv.style.backgroundImage = `url('${rankIconPath}${rankIconConfig[recruit.rank]}')`;
} else {
    faceDiv.style.backgroundImage = `url('${recruit.faceImageUrl}')`;
}
```

### 2. CSS Changes (`style.css`)

#### 2a. Add dogtag background to `.unit-card-details`:
The dogtag image should cover the entire details section as a backdrop, with name/rank/xp text overlaid on top.

```css
.unit-card-details {
    /* existing styles */
    background-image: url('assets/images/ui/dogtag.png');
    background-size: cover;
    background-position: center;
    /* Ensure text remains legible - may need to add text shadow or adjust colors */
}
```

#### 2b. Fallen unit override:
For fallen units, the dogtag might need grayscale or dimmed treatment to match the fallen aesthetic.

```css
.unit-card.fallen .unit-card-details {
    filter: grayscale(50%) brightness(0.8);
}
```
