# Possum Turret Implementation Plan

## Summary
Add a new possum turret entity that spawns at map edges, can be shut down from behind within 60px by pressing E, rotates to face a "middle" sprite when shut down.

---

## Image Assets
Found 8 directional sprites at `assets/images/objects/possums/turrets/possum_turret_1_{direction}.png`:
- `n`, `ne`, `e`, `se`, `s`, `sw`, `w`, `nw`

User wants only **3 direction arcs** based on spawn position:
- **Top half spawn** → faces West arc: W, SW, S, SE, E (5 sprites)
- **Right side spawn** → faces North arc: N, NW, W, SW, S (5 sprites)
- Player spawns bottom-left, so these two zones don't overlap

## Step-by-Step Implementation

### Step 1: Add Weapon Definition (`js/config.js`)
Add `POSSUM_TURRET_WEAPON` to `CONFIG.WEAPON_DEFINITIONS`, following the existing possum weapon pattern:
```js
POSSUM_TURRET_WEAPON: {
    name: 'Possum Turret',
    damage: 20,
    rof: 1.5,
    range: 400,
    projectileSpeed: 500,
    projectileColor: '#ff6600',
    accuracyStationary: 0.85,
    bulletLifetime: 2.0,
    isDefaultWeapon: false,
    phaseUnlocked: 3,
    sfxFireKey: 'possum_turret_fire',
    muzzleFlashScale: 0.5
}
```

### Step 2: Add `PossumTurret` Class (`js/possumTurret.js`)
Create new file with:
- Constructor: x, y, direction arc (array of direction strings), game reference
- Properties: `x`, `y`, `width`, `height`, `facingDirection`, `isShutdown`, `interactionRadius = 60`
- `render()`: draws current sprite based on `facingDirection`, shows "Press E to shut down" prompt when player nearby and not shutdown
- `shutdown()`: called when player presses E from behind — sets `isShutdown = true`, rotates to middle sprite of arc
- `getNearestRaccoonInRange()`: distance check from center, returns nearest living raccoon within 60px
- `getNearestRaccoonBehind()`: override that checks player is on the OPPOSITE side of facing direction
- `update()`: if not shutdown, aim at nearest player and fire weapon at configured rate

### Step 3: Add Preloading (`js/game.js`)
In `preloadMiscAssets()` (around line 900), add:
```js
// Possum Turret
const turretDir = 'assets/images/objects/possums/turrets/';
const turretDirections = ['n', 'ne', 'e', 'se', 's', 'sw', 'w', 'nw'];
for (const dir of turretDirections) {
    const key = `possum_turret_1_${dir}`;
    if (!this.preloadedImages[key]) {
        imagePromises.push(new Promise((resolve) => {
            const img = new Image();
            img.onload = () => { this.preloadedImages[key] = img; resolve(); };
            img.onerror = () => { this.preloadedImages[key] = null; resolve(); };
            img.src = turretDir + `possum_turret_1_${dir}.png`;
        }));
    }
}
```

### Step 4: Add Spawn Logic (`js/levelGenerator.js`)
In `generate()` where obstacles are placed:
- Determine if spawn position is in top half (y < mapHeight / 2) → assign W arc
- Or right side (x > mapWidth / 2) → assign N arc
- Add `possum_turret` to obstacle definitions with `phaseUnlocked: 3`, `spawnLimit: 1`
- Place at map edge positions (top edge or right edge only)

### Step 5: Add Interaction Handler (`js/game.js`)
Add `handlePossumTurretShutdown()` similar to `handleIntelConsoleInteraction`:
```js
handlePossumTurretShutdown() {
    for (const turret of this.possumTurrets) {
        if (turret.isShutdown) continue;
        const behind = turret.getNearestRaccoonBehind();
        if (behind) {
            turret.shutdown();
            break;
        }
    }
}
```

### Step 6: Wire E Key (`js/input.js`)
In the E key handler, add:
```js
if (this.game.handlePossumTurretShutdown) {
    this.game.handlePossumTurretShutdown();
}
```

### Step 7: Add to Campaign Phase Spawning (`js/campaignRules.js`)
Add `possum_turret` to `GUARD_SPAWNABLES` with `phaseUnlocked: 3` and spawn limit control.
