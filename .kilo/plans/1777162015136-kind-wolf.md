# Plan: Add Bullet Sprite Support to Weapons

## Overview
Add sprite-based bullet rendering to all weapons, with fallback to canvas drawing. Each weapon will have a `bulletSpritePath` and `bulletSpriteScale` parameter. For now, all weapons will use `bullet_gold_1.png`.

## Files to Modify

### 1. `js/config.js` - Add sprite parameters to weapon definitions
- Add `bulletSpritePath: 'assets/images/projectiles/bullet_gold_1.png'` to ALL weapon definitions
- Add `bulletSpriteScale: 1.0` (or appropriate value) to ALL weapon definitions
- Add global fallback config in `PROJECTILES.BULLET`:
  ```javascript
  BULLET: {
      LIFETIME: 0.7,
      MAX_SPREAD_ANGLE_RADIANS: Math.PI / 6,
      DESPAWN_WORLD_BUFFER: 100,
      SPRITE_PATH: 'assets/images/projectiles/bullet_gold_1.png',  // default fallback
      SPRITE_SCALE: 1.0  // default fallback
  }
  ```

### 2. `js/weapon.js` - Update Weapon class and Projectile class
**Weapon class (line 1-16):**
- Add `bulletSpritePath` and `bulletSpriteScale` parameters to constructor
- Store as `this.bulletSpritePath` and `this.bulletSpriteScale`

**Projectile class (line 43-209):**
- In `reset()` method: store the weapon's bullet sprite path and scale
- In `render()` method: check if sprite exists, use `drawImage()` if so, fallback to `ctx.arc()` otherwise
- Pattern to follow (from GrenadeProjectile):
  ```javascript
  render(ctx) {
      const sprite = this.game.preloadedImages[this.bulletSpritePath];
      if (sprite && sprite.complete && sprite.naturalWidth > 0) {
          const w = sprite.naturalWidth * this.bulletSpriteScale;
          const h = sprite.naturalHeight * this.bulletSpriteScale;
          ctx.drawImage(sprite, this.x - w/2, this.y - h/2, w, h);
      } else {
          ctx.fillStyle = this.color;
          ctx.beginPath();
          ctx.arc(this.x, this.y, this.size, 0, Math.PI * 2);
          ctx.fill();
      }
  }
  ```

### 3. `js/game.js` - Preload bullet sprites
- In the asset preloading section (~lines 323-518), add preloading for bullet sprites
- Can preload from `PROJECTILES.BULLET.SPRITE_PATH` as default, plus any weapon-specific paths
- Pattern:
  ```javascript
  // Preload default bullet sprite
  const defaultBulletSpritePath = CONFIG.PROJECTILES?.BULLET?.SPRITE_PATH;
  if (defaultBulletSpritePath) {
      preloadImage(defaultBulletSpritePath);
  }
  // Preload weapon-specific bullet sprites
  for (const weaponDef of Object.values(CONFIG.WEAPON_DEFINITIONS || {})) {
      if (weaponDef.bulletSpritePath) {
          preloadImage(weaponDef.bulletSpritePath);
      }
  }
  ```

## Implementation Order

1. **config.js**: Add sprite parameters to all weapon definitions + global BULLET config
2. **game.js**: Add bullet sprite preloading
3. **weapon.js**: Update Weapon constructor, Projectile reset(), and Projectile render()

## Key Considerations

- **Fallback behavior**: If sprite fails to load, bullets render as colored circles (current behavior)
- **Sprite sizing**: `bulletSpriteScale` multiplies `naturalWidth/naturalHeight`, similar to grenade sprite pattern
- **No breaking changes**: Existing weapons without sprite params will use global fallback from `PROJECTILES.BULLET`
- **Memory**: Bullet sprites are small, preload once and reuse across all projectiles
